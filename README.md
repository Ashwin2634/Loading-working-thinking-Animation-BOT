# GrokBot

A lightweight, expressive React component inspired by the Grok Bot avatar.  
Features multiple emotional states, real-time eye tracking, automatic blinking, and smooth springy animations — perfect for dashboards, AI assistants, and loading indicators.

## Features

- 🎭 **7 emotional states**: `idle`, `thinking`, `loading`, `excited`, `happy`, `curious`, `sleepy`
- 👀 **Eye tracking** — eyes follow the mouse/pointer
- ✨ Automatic blinking
- 🎨 Fully customizable colors and size
- 🪶 Zero external animation libraries (pure CSS + React)
- ♿ Accessible (`role="img"` + `aria-label`)
- 📱 Works great on both light and dark themes
